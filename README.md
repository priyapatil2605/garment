# DragonFruit Distributed Store

A distributed shopping application for the Distributed Computing lab.

## Modules
- frontend: React and TypeScript user interface
- backend/core: shopping APIs and business logic
- backend/cluster: distributed server coordination
- database: PostgreSQL migrations and seed data
- workers/mapreduce: MapReduce experiments
- workers/mpi: MPI experiments
- contracts: shared API contracts
